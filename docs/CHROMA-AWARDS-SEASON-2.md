## How judging works (terms summary)

1. **Preliminary** — pass/fail + score 1–10 on viability + requirements.
2. **Qualifiers** — top **66%** per category by avg score.
3. **Quarter-finals** — re-score → top **50** per category.
4. **Semi-finals** — top **22** per category.
5. **Finals** — division/category ranks (Grand / 2nd / 3rd / 4th–11th / 12th–22nd) + **separate sponsor award finals** (tool tag + proof + prior round scores).

**Criteria (25% each):** Theme & division fit · Creativity & AI innovation · Craft & technical polish · Sound & emotional impact.

**Prize stacking:** one main prize per division per submission; **multiple sponsor prizes** from **different** partners OK; **not** two prizes from the **same** partner on one entry.

## Submission rules that bite (read before upload)

| Rule | Implication for you |
|------|---------------------|
| **≥18** (or local age of majority) | Individual or team; **not** on behalf of a company |
| **≥1 AI tool** per entry | Disclose tools accurately on the form |
| **English** | Non–music-video: **voiced OR subtitled in English** (or no dialogue) |
| **Public embed** | Link must embed in gallery — **not private, password-protected, or unlisted** |
| **Thumbnail + download link** | Required fields on submit |
| **Music** | Original, licensed, permitted, or **AI music** (e.g. ElevenMusic) |
| **No third-party IP** | No franchise/brand slop; parody OK but generic IP rehash hurts score |
| **No deepfakes** | Likeness/voice permissions required |
| **Prior work** | OK if **not** submitted to prior Chroma/Project Odyssey season; partner-program incubation OK |
| **Multiple entries** | Allowed if **unique and substantially different** |
| **Sponsor awards** | **Tool tag** + significant use + **proof** on request |
| **Edits** | Drafts OK until **preliminary judging** locks the entry |

**India:** not listed as excluded (OFAC/sanctioned regions are). Winners may need **W-8BEN** / tax handling.

**License:** you keep IP; ElevenLabs + sponsors get broad promo/evaluation license (see terms §9). Optional **distribution opt-in** to streaming partners.
