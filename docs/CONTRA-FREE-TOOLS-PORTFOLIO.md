## Free on Contra (use in this order)

| # | Free tool | What it does | Link |
|---|-----------|--------------|------|
| 1 | **Profile + projects** | Case studies · services · social links | [contra.com](https://contra.com) → Dashboard |
| 2 | **Portfolio Magic** (AI) | Bio · one-liner · project/service titles from prompts | [Portfolio Magic blog](https://contra.com/blog/portfolio-magic-by-contra) |
| 3 | **Import from URL** | Pull LinkedIn · GitHub · Medium · IG into a project | Same flow in Portfolio Magic setup |
| 4 | **Sydney template** | **Free** portfolio site theme for all users | [Sydney](https://contra.com/portfolios/sydney) · Dashboard → **Your Portfolio** |
| 5 | **Community / challenges** | Submissions = portfolio proof (Cantina · Rive · invideo) | [Community topics](https://contra.com/community) |
| 6 | **Expert / tool badges** | Lovable · etc. after partner apply — trust on profile | [SITES C1](../SITES-AND-PLATFORMS-GREEN.md) |
| 7 | **Commission-free payouts** | Contracts/invoices when you land a client (no Contra % on creative side) | [Pricing](https://contra.com/pricing) |

**Paid later (skip until 1 client or Pro ROI):** full template library · custom domain · analytics — **Contra Pro** (~$29/mo per [pricing](https://contra.com/pricing)).
